# Stickers

The animations in this folder are Google's Noto Animated Emoji
(https://googlefonts.github.io/noto-emoji-animation/), used under the
Creative Commons Attribution 4.0 licence (CC BY 4.0,
https://creativecommons.org/licenses/by/4.0/). Files are the unmodified
Lottie exports, renamed from their code points to readable ids.
